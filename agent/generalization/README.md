# generalization

Taking the method beyond two cats in one room (Project Plan: target users and "find any
object").

Scope: other pets and multi-cat households, new homes and camera views, and any object
through open-vocabulary detection or segmentation (e.g. SAM 3.1). The framework is built to
generalize; this folder holds what makes that concrete: configs, adapters and evaluation on
scenes the system was not tuned on.
